# School Management System (SMS + LMS)

Multi-school SaaS: Super Admin creates schools and principal accounts; schools pay monthly.

- Frontend: Next.js
- Backend: Node.js + Express
- Database: MySQL on Oracle Cloud (OCI)

Status: planning. See [docs/FEATURES.md](docs/FEATURES.md) for the full feature list.

The previous MERN codebase was removed; it remains in git history (last commit `e5e766f`).
